# Digidex 

## Sobre o projeto

A Digidex é uma Pokédex de Digimons desenvolvida para permitir que os usuários pesquisem e conheçam diferentes personagens do universo Digimon.

O projeto conta com páginas para pesquisa, exploração, favoritos, estatísticas e configurações. As informações dos Digimons são obtidas através da Digi-API.

## Funcionalidades

- Pesquisar Digimons pelo nome ou ID.
- Visualizar informações como nível, tipo e atributo.
- Consultar a imagem do Digimon.
- Adicionar e remover Digimons dos favoritos.
- Filtrar Digimons por categoria.
- Visualizar estatísticas.
- Alterar entre tema claro e escuro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Digi-API
- LocalStorage

## Como executar
1. Clone ou baixe o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo html/inicio.html utilizando o navegador ou a extensão Live Server.
4. Para pesquisar Digimons, é necessário ter acesso à internet.

## API
Utilizamos a Digi-API para buscar as informações dos Digimons.
https://digi-api.com/
